# RCL v0.5 Camera Deployment Producer

This helper closes the gap between a real camera runtime and the existing `camera-perception-series` HIL boundary.

```text
REAL CAMERA
   ↓
deployment frame reader
   ↓
retained frame evidence
   ↓
deployment inferencer
   ↓
semantic predicate + confidence
   ↓
camera-perception-series
   ↓
Camera Semantic HIL
```

## Dependency boundary

RCL core does not require OpenCV, YOLO, TensorRT, VLM, or one Jetson camera stack. Deployments inject:

- a frame reader returning `(frame, frame_ref)`;
- an inferencer returning `semantic_state`, `predicate`, `confidence`, and optional provenance.

`collect_camera_perception_series()` validates and assembles the portable camera evidence series.

The optional `build_opencv_frame_reader()` helper lazily imports OpenCV and supports either a V4L2 index or a deployment-supported GStreamer pipeline string. Every captured frame is persisted before it can become RCL evidence.

## Jetson pattern

A Jetson deployment can run:

```bash
python examples/v0.5-hil/build_camera_perception.py \
  --source 0 \
  --inferencer my_perception:infer \
  --evidence-dir ./evidence/frames \
  --output camera-perception.json \
  --series-id jetson-camera-run-001 \
  --robot-id robot-b \
  --camera-component-id csi-camera-01 \
  --model-id clearance-model \
  --runtime tensorrt
```

The injected function receives one frame and returns, for example:

```python
def infer(frame):
    return {
        "semantic_state": "state.sitting_area_clear",
        "predicate": True,
        "confidence": 0.94,
        "strategy_id": "target.camera_clearance",
        "evidence_refs": ["file:///.../inference.json"],
    }
```

For a CSI camera, `--source` may be a GStreamer pipeline accepted by the Jetson OpenCV build.

## Evidence rule

A captured frame must have a non-empty retained `frame_ref`. The producer refuses an inference without semantic state, a boolean predicate, and confidence in `[0, 1]`.

This producer does not grant HIL evidence grade by itself. The resulting `camera-perception-series` still must pass through the Camera Semantic HIL deployment path with the existing deployment attestation and external evidence requirements.

## Deployment responsibilities

Camera calibration, focus/exposure, model choice, TensorRT/ONNX/YOLO integration, preprocessing, semantic-state logic, threshold tuning, scene coverage, occlusion handling, and physical safety remain deployment responsibilities.
