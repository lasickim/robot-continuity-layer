# RCL v0.5 ContinuityScore

`ContinuityScore v0.1` converts a behavioral compatibility report into an identity-weighted continuity estimate without inventing evidence for unvalidated substitutions.

## Inputs

```text
ContinuityProfile
+ IdentityConstraint
+ Compatibility Mapping Report
+ optional substitution assessments
```

The score is **not** a task-success metric. It estimates how much of the source robot's declared behavioral identity can be preserved on the target embodiment.

## Weighting

Each constrained trait receives:

```text
effective_weight = importance × source_confidence
```

`importance` comes from `IdentityConstraint`.

`source_confidence` comes from the observed `BehavioralSignature` trait.

`preservation_mode` is not multiplied again because doing so would double-count identity importance. Instead, `identity_critical` is used as a hard diagnostic: any failed critical constraint is surfaced separately in the report.

## Fidelity

### EXACT

```text
fidelity = 1.0
```

### APPROXIMATE

Direct numeric approximations are scored against the declared identity tolerance.

For absolute tolerance:

```text
fidelity = max(0, 1 - absolute_error / allowed_error)
```

For relative tolerance, the same relationship is applied to normalized relative error.

A target value at the tolerance boundary therefore has fidelity `0.0`. Values outside the policy envelope also remain `0.0`.

### UNSUPPORTED

```text
fidelity = 0.0
```

### SUBSTITUTE

RCL does **not** assign an arbitrary default fidelity to a substitute.

If no external assessment exists:

```text
fidelity ∈ [0.0, 1.0]
```

The final continuity result is therefore a lower/upper bound rather than a fabricated single score.

If a deployment, HIL, physical experiment, or user study later provides a substitution fidelity and evidence refs, the interval collapses toward a resolved score.

## Summary fields

A ContinuityScore report includes:

- `lower_bound`
- `upper_bound`
- optional `resolved_score`
- `policy_coverage_score`
- `resolved_weight_fraction`
- `identity_critical_ok`
- `identity_critical_failures`

### Policy coverage

`policy_coverage_score` is the identity-weighted fraction of mappings whose `IdentityConstraint` is currently satisfied. It is deliberately separate from behavioral fidelity.

For example, an approved substitute may satisfy policy while its perceptual equivalence is still unmeasured.

## Reference A → B result

The current reference Robot A → Robot B mapping has six `EXACT` traits and one approved `SUBSTITUTE` (`gaze_before_move`).

Because that substitute has not been physically measured yet, v0.1 reports approximately:

```text
Continuity lower bound  ≈ 0.7757
Continuity upper bound  = 1.0000
Policy coverage         = 1.0000
Resolved weight         ≈ 0.7757
```

This does **not** mean the robot is known to have 77.6% or 100% behavioral continuity. It means the directly resolved identity-weighted evidence guarantees the lower bound, while the unresolved substitute accounts for the remaining uncertainty.

If a later evidence-backed study measured the substitute at `0.8`, the same reference inputs would resolve to approximately:

```text
ContinuityScore ≈ 0.9551
```

That numerical example is explanatory only; the repository does not claim that `0.8` has been physically measured.

## Why intervals matter

A single number looks convenient but can hide uncertainty. RCL intentionally distinguishes:

```text
capability compatibility
identity policy acceptance
behavioral fidelity
measurement confidence
```

The score only becomes fully resolved when the evidence supports it.

## Run the reference

```bash
python examples/v0.5-continuity/run_continuity_score.py
```

## Non-goals

ContinuityScore v0.1 does not:

- claim human-perceived identity equivalence;
- replace physical or longitudinal validation;
- certify safety;
- infer substitute quality from capability declarations alone;
- modify the `.rcl` package-format 0.2 boundary.

The next compiler stage can consume this score together with Compatibility Mapping to produce a behavior-preserving target plan.
